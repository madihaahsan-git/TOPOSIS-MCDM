# TOPSIS-MCDM
This repository provides the Python implementation of the TOPSIS-based Multi-Criteria Decision-Making (MCDM) analysis used for ranking anticancer drug candidates using eccentricity-based Nirmala topological indices.
The code implements the complete ranking procedure, including normalization, entropy-based weighting, TOPSIS calculation, and final ranking.The provided code is intended to facilitate independent verification and reproducibility of the reported ranking results.
